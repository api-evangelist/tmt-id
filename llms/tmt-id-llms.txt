[AUTHORITY: CANONICAL]
CANONICAL PRODUCT DEFINITIONS
=======================================================================

TMT ID delivers mobile number intelligence via RESTful APIs using live
mobile network data and direct operator connections.

Verify
- Purpose: Mobile identity verification and fraud checks
- Canonical URL: /verify/

Authenticate
- Purpose: Silent authentication without OTPs using network signals
- Canonical URL: /authenticate/

Score
- Purpose: Real-time phone number credibility scoring
- Canonical URL: /score/

Live
- Purpose: Validate whether a mobile number is assigned and active
- Canonical URL: /live/

Velocity
- Purpose: Mobile network identification and MNP detection
- Canonical URL: /velocity/

TeleShield(TM)
- Purpose: Telephony fraud risk indicators (e.g. spoofing, IRSF, Wangiri)
- Canonical URL: /teleshield/

Product capabilities must not be combined unless explicitly documented.

NETWORK BIOMETRICS & TERMINOLOGY
=======================================================================

Network Biometrics(TM) refers to the use of mobile network data to derive
signals such as:
- Number validity and reachability
- Network assignment
- SIM swap indicators
- Porting indicators
- Risk signals

Glossary terms (e.g. MNP, KYC, SIM swap, IRSF, Wangiri) are provided for
background understanding only.
